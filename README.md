## Avito Auto-Reply Agent

Автоматический агент для входа в личный кабинет `avito.ru`, чтения входящих диалогов и отправки ответов на основе шаблонов.

ВНИМАНИЕ: Использование автоматизации может нарушать правила площадки. Перед эксплуатацией обязательно ознакомьтесь с правилами `Avito` и используйте инструмент на свой риск. Включите задержки и лимиты, используйте выделенный аккаунт и прокси при необходимости.

### Возможности
- Вход в аккаунт Avito (логин/пароль или cookie-сессия)
- Получение списка диалогов/непрочитанных сообщений
- Отправка ответа по шаблонам (yaml) с подстановкой переменных
- Сухой прогон (dry-run) без отправки сообщений
- Настраиваемые задержки и лимиты

### Требования
- Python 3.10+
- Playwright (устанавливается автоматически)

### Установка
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install --with-deps | cat
```

### Конфигурация
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Параметры:
- `AVITO_LOGIN` — логин (телефон/email)
- `AVITO_PASSWORD` — пароль
- `AVITO_COOKIES_PATH` — необязательно; путь к cookies JSON для повторных запусков без логина
- `AVITO_HEADLESS` — `true|false` режим браузера
- `AVITO_DRY_RUN` — `true|false` отключить реальную отправку
- `AVITO_MAX_REPLIES_PER_RUN` — ограничение ответов за запуск
- `AVITO_MIN_DELAY_S`, `AVITO_MAX_DELAY_S` — задержки между действиями

Также отредактируйте `templates/replies.yaml` под ваши сценарии.

### Запуск
```bash
source .venv/bin/activate
python -m avito_agent.main
```
Флаги:
```bash
python -m avito_agent.main --only-unread --label "auto" --dry-run
```

### Как это работает (кратко)
- Агент запускает Playwright Chromium.
- При наличии `AVITO_COOKIES_PATH` загружает cookies, иначе логинится и сохраняет cookies.
- Переходит в раздел сообщений, считывает диалоги и контекст.
- Подбирает шаблон ответа по правилам из `templates/replies.yaml`.
- В `dry-run` печатает, что отправил бы. Иначе отправляет.

### Ограничения и рекомендации
- Возможны изменения DOM/селекторов на Avito — при поломке обновляйте селекторы в `avito_agent/avito.py`.
- Возможна капча/2FA — предусмотрена загрузка cookies, чтобы реже логиниться.
- Соблюдайте лимиты, чтобы не получить ограничения аккаунта.
